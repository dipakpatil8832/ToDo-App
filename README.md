✅ To-Do List Web Application

A simple and attractive task management web application built using Python Flask with features to Add, Edit, Delete, Search, and Complete Tasks.
All tasks are stored in a JSON file, making the app lightweight and easy to run anywhere!

📌 Features

✅ Add new tasks with due date
✅ Edit existing tasks anytime
✅ Delete tasks easily
✅ Mark tasks as completed
✅ Search tasks instantly 🔍
✅ Beautiful UI using Bootstrap
✅ JSON-based task storage (No database required)
✅ Easy to navigate and mobile responsive

🛣️ Future Enhancements

✅ Task priority (High / Medium / Low)
✅ Category / Tag support
✅ User authentication
✅ Notification reminders
✅ Database support (MySQL / MongoDB)
